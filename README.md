# ☕ Fire Pot — Cafe Website

A responsive multi-page cafe website created as part of the **3-1 Essentials of Web Programming (EWP)** coursework. The project showcases a modern cafe landing page with multiple sections using only **HTML5** and **CSS3**, without any frameworks or backend.

---

## ✨ Features

- Modern landing page with hero section
- Multi-page navigation
- Responsive navigation bar
- About Us page
- Services page
- Contact page
- Login page (UI only)
- Reusable CSS styling
- Clean and simple user interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (placeholder for future enhancements)

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/karthikeya0922/cafe-website.git
```

Navigate into the project:

```bash
cd cafe-website
```

Open **index.html** in your preferred browser.

Alternatively, run a local server:

```bash
python -m http.server 8000
```

Then visit:

```
http://localhost:8000
```
